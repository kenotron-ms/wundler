## Mission

Stand up the Profile-Guided Optimization Store: a SQLite-backed analytics service that ingests the JSONL telemetry stream the ABS writes, computes co-request statistics, runs a C³-style clustering pass over chunk pairs, and writes three advisory fields back into `manifest.json` — `co_request_score`, `median_load_order`, and `suggested_merge`. The ABS reloads the manifest on its next cycle and immediately starts emitting better prefetch hints. No rebuild required.

This plan delivers Level 2 of the three-level deployment model. After Plan 5, the system is self-tuning: every deploy collects telemetry, the PGO Store refines hints between deploys, and the next build can apply `suggested_merge` to physically reorganize chunks.

## Goal

Implement `crates/cloudpack-pgo` as a new workspace member with a CLI (`cloudpack pgo ingest | analyze | apply | status`) backed by these libraries:
- `store.rs` — SQLite schema, idempotent inserts, co-request queries.
- `ingestor.rs` — streaming JSONL parser that maps `TelemetryEvent` rows to `SessionRecord` rows.
- `clustering.rs` — C³ conditional-probability matrix + greedy bidirectional merge selection.
- `hints.rs` — per-chunk score computation against an in-memory `ChunkManifest`.
- `updater.rs` — atomic write-only update of PGO fields in `manifest.json` (no module/chunk changes).

## Tech Stack

- Rust 2021 + `anyhow`/`thiserror`
- `rusqlite` (bundled SQLite — no system dependency)
- `serde` / `serde_json` for telemetry parsing and manifest patching
- `tempfile` for atomic write-rename
- Re-uses `cloudpack-core::ContentHash` and `cloudpack-graph::ChunkManifest`/`Chunk` from Plans 1 and 2

## Operating Invariants

1. **Hints are advisory.** The pipeline never trusts PGO output for correctness. A wrong `suggested_merge` just leaves performance on the table; it cannot break a build.
2. **Idempotent ingest.** Re-running `cloudpack pgo ingest` over the same log is a no-op. The SQLite PK on `(session_id, chunk_id)` enforces this.
3. **Atomic manifest update.** `updater.rs` writes to a temp file in the same directory and `fs::rename`s it into place. A crashed `cloudpack pgo apply` cannot leave a half-written manifest.
4. **Floor before clustering.** With fewer than `min_sessions` (default 100), `compute_clusters` returns an empty map. C³ on tiny samples produces nonsense merges.
5. **Deterministic output.** Two runs of `cloudpack pgo apply` against the same DB and manifest produce byte-identical JSON. Tiebreaks use sorted chunk ids.

```rust
pub struct ChunkHint {
    pub co_request_score: f64,
```

```rust
//! SQLite-backed co-request matrix.
//!
//! One row per `(session_id, chunk_id)` pair, capturing the load
//! position of `chunk_id` within `session_id`. All clustering queries
//! reduce to SQL aggregates over this table.

use anyhow::{Context, Result};
use rusqlite::Connection;
use std::path::Path;
use std::sync::Mutex;

const SCHEMA_SQL: &str = "
CREATE TABLE IF NOT EXISTS sessions (
    session_id   TEXT    NOT NULL,
    entry_point  TEXT    NOT NULL,
    chunk_id     TEXT    NOT NULL,
    load_order   INTEGER NOT NULL,
    timestamp_ms INTEGER NOT NULL,
    PRIMARY KEY (session_id, chunk_id)
);
CREATE INDEX IF NOT EXISTS idx_chunk ON sessions(chunk_id);
CREATE INDEX IF NOT EXISTS idx_entry ON sessions(entry_point, chunk_id);
";

pub struct PgoStore {
    pub(crate) conn: Mutex<Connection>,
}

impl PgoStore {
    /// Open a SQLite store at `db_path`. Creates the file and schema if missing.
    pub fn open(db_path: &Path) -> Result<Self> {
        let conn = Connection::open(db_path)
            .with_context(|| format!("open sqlite at {}", db_path.display()))?;
        Self::init(conn)
    }

    /// In-memory store. Used by tests.
    pub fn open_in_memory() -> Result<Self> {
        let conn = Connection::open_in_memory().context("open in-memory sqlite")?;
        Self::init(conn)
    }

    fn init(conn: Connection) -> Result<Self> {
        conn.execute_batch(SCHEMA_SQL).context("apply PGO schema")?;
        Ok(Self {
            conn: Mutex::new(conn),
        })
    }

    /// Total distinct sessions in the store.
    pub fn session_count(&self) -> Result<usize> {
        let conn = self.conn.lock().expect("PGO store mutex poisoned");
        let n: i64 = conn
            .query_row(
                "SELECT COUNT(DISTINCT session_id) FROM sessions",
                [],
                |row| row.get(0),
            )
            .context("session_count query")?;
        Ok(n as usize)
    }

    /// Test/diagnostic helper — names of all user tables.
    pub fn list_tables(&self) -> Result<Vec<String>> {
        let conn = self.conn.lock().expect("PGO store mutex poisoned");
        let mut stmt = conn
            .prepare("SELECT name FROM sqlite_master WHERE type='table' ORDER BY name")
            .context("prepare list_tables")?;
        let rows = stmt
            .query_map([], |row| row.get::<_, String>(0))
            .context("query list_tables")?;
        let mut out = Vec::new();
        for r in rows {
            out.push(r.context("read table name")?);
        }
        Ok(out)
    }

    /// Test/diagnostic helper — names of all user indexes.
    pub fn list_indexes(&self) -> Result<Vec<String>> {
        let conn = self.conn.lock().expect("PGO store mutex poisoned");
        let mut stmt = conn
            .prepare("SELECT name FROM sqlite_master WHERE type='index' AND name NOT LIKE 'sqlite_%' ORDER BY name")
            .context("prepare list_indexes")?;
        let rows = stmt
            .query_map([], |row| row.get::<_, String>(0))
            .context("query list_indexes")?;
        let mut out = Vec::new();
        for r in rows {
            out.push(r.context("read index name")?);
        }
        Ok(out)
    }
}
```

```rust
    /// Insert one session as N rows (one per chunk in `chunk_sequence`).
    /// Returns the number of rows inserted. Duplicate `(session_id, chunk_id)`
    /// pairs are silently skipped (see Task 5).
    pub fn insert_session(&self, record: &crate::types::SessionRecord) -> Result<usize> {
        let mut conn = self.conn.lock().expect("PGO store mutex poisoned");
        let tx = conn.transaction().context("begin insert_session tx")?;
        let mut inserted = 0usize;
        {
            let mut stmt = tx
                .prepare(
                    "INSERT OR IGNORE INTO sessions \
                     (session_id, entry_point, chunk_id, load_order, timestamp_ms) \
                     VALUES (?1, ?2, ?3, ?4, ?5)",
                )
                .context("prepare insert")?;
            for (i, chunk_id) in record.chunk_sequence.iter().enumerate() {
                let n = stmt
                    .execute(rusqlite::params![
                        record.session_id,
                        record.entry_point,
                        chunk_id,
                        i as i64,
                        record.timestamp_ms as i64,
                    ])
                    .context("execute insert")?;
                inserted += n;
            }
        }
        tx.commit().context("commit insert_session tx")?;
        Ok(inserted)
    }

    /// How many distinct sessions loaded `chunk_id`.
    pub fn chunk_load_count(&self, chunk_id: &str) -> Result<usize> {
        let conn = self.conn.lock().expect("PGO store mutex poisoned");
        let n: i64 = conn
            .query_row(
                "SELECT COUNT(DISTINCT session_id) FROM sessions WHERE chunk_id = ?1",
                [chunk_id],
                |row| row.get(0),
            )
            .context("chunk_load_count query")?;
        Ok(n as usize)
    }
```

```rust
    /// Median of `load_order` values observed for `chunk_id`.
    /// Returns 0.0 when the chunk has no observations.
    ///
    /// SQLite has no built-in MEDIAN; we collect the values in sorted
    /// order and compute the median in Rust. With the `idx_chunk` index
    /// this is `O(n)` on rows for `chunk_id` only.
    pub fn median_load_order(&self, chunk_id: &str) -> Result<f64> {
        let conn = self.conn.lock().expect("PGO store mutex poisoned");
        let mut stmt = conn
            .prepare(
                "SELECT load_order FROM sessions WHERE chunk_id = ?1 ORDER BY load_order",
            )
            .context("prepare median_load_order")?;
        let rows = stmt
            .query_map([chunk_id], |row| row.get::<_, i64>(0))
            .context("query median_load_order")?;
        let mut values: Vec<i64> = Vec::new();
        for r in rows {
            values.push(r.context("read load_order")?);
        }
        if values.is_empty() {
            return Ok(0.0);
        }
        let n = values.len();
        let median = if n % 2 == 1 {
            values[n / 2] as f64
        } else {
            let lo = values[n / 2 - 1] as f64;
            let hi = values[n / 2] as f64;
            (lo + hi) / 2.0
        };
        Ok(median)
    }
```

```rust
//! JSONL telemetry ingestor.
//!
//! Reads the ABS's `TelemetryEvent` log (see Plan 4) one line at a
//! time and converts each event into a `SessionRecord` whose
//! `chunk_sequence` is the `chunks_served` vector in load order.

use crate::types::SessionRecord;
use anyhow::{anyhow, Context, Result};
use serde::Deserialize;

/// Mirror of `cloudpack_abs::types::TelemetryEvent`, declared here so
/// `cloudpack-pgo` does not need to depend on `cloudpack-abs` (which pulls
/// in axum, tokio, etc.). The wire shape is fixed by Plan 4 and
/// versioned via the manifest `build_id`.
#[derive(Debug, Deserialize)]
struct WireTelemetryEvent {
    session_id: String,
    entry_point: String,
    chunks_served: Vec<String>,
    #[allow(dead_code)]
    client_had: Vec<String>,
    timestamp_ms: u64,
}

/// Parse one line of the JSONL telemetry log.
///
/// Returns:
/// - `Ok(None)` for empty or whitespace-only lines.
/// - `Ok(Some(record))` for a well-formed event.
/// - `Err(_)` for malformed JSON or missing required fields.
pub fn parse_event_line(line: &str) -> Result<Option<SessionRecord>> {
    let trimmed = line.trim();
    if trimmed.is_empty() {
        return Ok(None);
    }
    let event: WireTelemetryEvent = serde_json::from_str(trimmed)
        .map_err(|e| anyhow!("malformed telemetry line: {e}"))
        .context("parse telemetry JSON")?;

    Ok(Some(SessionRecord {
        session_id: event.session_id,
        entry_point: event.entry_point,
        chunk_sequence: event.chunks_served,
        timestamp_ms: event.timestamp_ms,
    }))
}
```

```rust
        let line = line.context("read telemetry line")?;
        stats.lines_read += 1;

        match parse_event_line(&line) {
            Ok(None) => continue,
            Err(_) => {
                stats.parse_errors += 1;
                continue;
            }
            Ok(Some(record)) => {
                let inserted = store
                    .insert_session(&record)
                    .context("insert ingested session")?;
                if inserted == 0 {
                    stats.sessions_skipped_duplicate += 1;
                } else {
                    stats.sessions_inserted += 1;
                }
            }
        }
    }

    Ok(stats)
}
```

```rust
//! C³-style chunk clustering.
//!
//! Inspired by BOLT's Call-Chain Clustering. We treat each chunk as a
//! "function" and each session as a "call chain". Pairs that co-occur
//! with high conditional probability *in both directions* are merge
//! candidates; we then greedily collapse those candidates under a
//! `max_merge_modules` constraint.

use crate::store::PgoStore;
use anyhow::Result;
use std::collections::HashMap;

/// Tunable thresholds for C³ clustering.
#[derive(Debug, Clone)]
pub struct C3Config {
    /// `P(b|a)` must exceed this for `a→b` to be a merge candidate.
    /// Both directions must clear the bar.
    pub merge_threshold: f64,
    /// Do not propose a merge whose combined module count exceeds this.
    pub max_merge_modules: usize,
    /// Skip clustering entirely if the store has fewer than this many sessions.
    pub min_sessions: usize,
}

impl Default for C3Config {
    fn default() -> Self {
        Self {
            merge_threshold: 0.70,
            max_merge_modules: 500,
            min_sessions: 100,
        }
    }
}

/// Compute `P(b|a)` for every ordered pair `(a, b)` in `chunk_ids`
/// where `a != b` and `load(a) > 0`.
///
/// Returned map: key = `(a, b)`, value = `co(a,b) / load(a)`.
pub fn conditional_probability_matrix(
    store: &PgoStore,
    chunk_ids: &[String],
) -> Result<HashMap<(String, String), f64>> {
    let mut out = HashMap::new();
    // Cache load counts to avoid redundant queries.
    let mut loads: HashMap<&str, usize> = HashMap::new();
    for c in chunk_ids {
        loads.insert(c.as_str(), store.chunk_load_count(c)?);
    }

    for a in chunk_ids {
        let load_a = *loads.get(a.as_str()).unwrap_or(&0);
        if load_a == 0 {
            continue;
        }
        for b in chunk_ids {
            if a == b {
                continue;
            }
            let co = store.co_load_count(a, b)?;
            let p = co as f64 / load_a as f64;
            out.insert((a.clone(), b.clone()), p);
        }
    }
    Ok(out)
}
```

```rust
use std::collections::HashSet;
use cloudpack_graph::ChunkManifest;

/// Compute per-chunk merge suggestions.
///
/// Returns a map from `chunk_id` to `Some(target_chunk_id)` when the
/// chunk should be merged into `target`, or `None` when no candidate
/// passed all gates.
///
/// Algorithm:
/// 1. Bail (empty suggestions) if the store holds fewer than
///    `config.min_sessions` sessions.
/// 2. Compute `P(b|a)` for every ordered pair of chunks present in the
///    manifest.
/// 3. Form bidirectional candidates `{a, b}` where both `P(b|a)` and
///    `P(a|b)` exceed `config.merge_threshold` and the combined module
///    count is at most `config.max_merge_modules`.
/// 4. Greedily process candidates by descending `P(b|a) + P(a|b)`,
///    breaking ties on lexicographic order of `(min_id, max_id)`.
/// 5. For each candidate, if neither side is already merged, record
///    the merge from the lexicographically-smaller id into the larger.
pub fn compute_clusters(
    store: &PgoStore,
    manifest: &ChunkManifest,
    config: &C3Config,
) -> Result<HashMap<String, Option<String>>> {
    // Seed result with None for every chunk in the manifest.
    let mut result: HashMap<String, Option<String>> = manifest
        .chunks
        .iter()
        .map(|c| (c.id.clone(), None))
        .collect();

    if store.session_count()? < config.min_sessions {
        return Ok(result);
    }

    let chunk_ids: Vec<String> = {
        let mut v: Vec<String> = manifest.chunks.iter().map(|c| c.id.clone()).collect();
        v.sort();
        v
    };

    let module_count: HashMap<&str, usize> = manifest
        .chunks
        .iter()
        .map(|c| (c.id.as_str(), c.modules.len()))
        .collect();

    let probs = conditional_probability_matrix(store, &chunk_ids)?;

    // Build candidate set: bidirectional, size-constrained, deterministic order.
    let mut candidates: Vec<(String, String, f64)> = Vec::new();
    for i in 0..chunk_ids.len() {
        for j in (i + 1)..chunk_ids.len() {
            let a = &chunk_ids[i];
            let b = &chunk_ids[j];
            let p_ab = probs.get(&(a.clone(), b.clone())).copied().unwrap_or(0.0);
            let p_ba = probs.get(&(b.clone(), a.clone())).copied().unwrap_or(0.0);
            if p_ab <= config.merge_threshold || p_ba <= config.merge_threshold {
                continue;
            }
            let combined = module_count.get(a.as_str()).copied().unwrap_or(0)
                + module_count.get(b.as_str()).copied().unwrap_or(0);
            if combined > config.max_merge_modules {
                continue;
            }
            candidates.push((a.clone(), b.clone(), p_ab + p_ba));
        }
    }

    // Sort by score desc, then by (a, b) ascending for full determinism.
    candidates.sort_by(|x, y| {
        y.2.partial_cmp(&x.2)
            .unwrap_or(std::cmp::Ordering::Equal)
            .then_with(|| x.0.cmp(&y.0))
            .then_with(|| x.1.cmp(&y.1))
    });

    // Greedy: each chunk may participate in at most one merge.
    let mut consumed: HashSet<String> = HashSet::new();
    for (a, b, _) in candidates {
        if consumed.contains(&a) || consumed.contains(&b) {
            continue;
        }
        // a < b by construction (i < j above). Merge a → b.
        result.insert(a.clone(), Some(b.clone()));
        consumed.insert(a);
        consumed.insert(b);
    }

    Ok(result)
}
```

```rust
//! Compute `PgoHints` from a `PgoStore` and a `ChunkManifest`.
//!
//! `co_request_score` is the fraction of all observed sessions in
//! which the chunk appeared within the first `INITIAL_WINDOW` chunks.
//! `median_load_order` and `suggested_merge` come straight from the
//! store / clustering pass.

use crate::clustering::{compute_clusters, C3Config};
use crate::store::PgoStore;
use crate::types::{ChunkHint, PgoHints};
use anyhow::Result;
use std::collections::HashMap;
use cloudpack_graph::ChunkManifest;

/// "First N chunks served" window used for `co_request_score`.
pub const INITIAL_WINDOW: usize = 3;

/// Compute per-chunk hints over every chunk in `manifest`.
///
/// Empty store: returns `co_request_score=0`, `median_load_order=0`,
/// `suggested_merge=None` for each chunk.
pub fn compute_hints(
    store: &PgoStore,
    manifest: &ChunkManifest,
    cluster_config: &C3Config,
) -> Result<PgoHints> {
    let sessions = store.session_count()?;
    let clusters = compute_clusters(store, manifest, cluster_config)?;

    let mut chunk_hints: HashMap<String, ChunkHint> = HashMap::with_capacity(manifest.chunks.len());
    for c in &manifest.chunks {
        let co_request_score = if sessions == 0 {
            0.0
        } else {
            let initial = store.initial_load_count(&c.id, INITIAL_WINDOW)?;
            initial as f64 / sessions as f64
        };

        let median_load_order = store.median_load_order(&c.id)?;
        let suggested_merge = clusters.get(&c.id).cloned().unwrap_or(None);

        chunk_hints.insert(
            c.id.clone(),
            ChunkHint {
                co_request_score,
                median_load_order,
                suggested_merge,
            },
        );
    }

    Ok(PgoHints {
        build_id: manifest.build_id.clone(),
        chunk_hints,
    })
}
```

```rust
//! Atomic application of `PgoHints` to a `manifest.json` on disk.
//!
//! Read → mutate in-memory `ChunkManifest` (PGO fields only) →
//! serialize → write to `manifest.json.tmp.<pid>` → `fs::rename`
//! over the original. Either the new file is fully in place or the
//! original is untouched.

use crate::types::PgoHints;
use anyhow::{anyhow, Context, Result};
use std::fs;
use std::io::Write;
use std::path::Path;
use cloudpack_graph::ChunkManifest;

/// Counters returned by `apply_hints`.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct UpdateStats {
    pub chunks_updated: usize,
    pub merge_suggestions: usize,
    pub manifest_build_id: String,
}

/// Apply `hints` to the manifest JSON at `manifest_path`.
///
/// Errors if:
/// - the manifest cannot be read or parsed,
/// - the manifest's `build_id` differs from `hints.build_id` (refuses
///   to apply hints computed against a different build),
/// - the write fails.
pub fn apply_hints(manifest_path: &Path, hints: &PgoHints) -> Result<UpdateStats> {
    let bytes = fs::read(manifest_path)
        .with_context(|| format!("read manifest {}", manifest_path.display()))?;
    let mut manifest: ChunkManifest = serde_json::from_slice(&bytes)
        .with_context(|| format!("parse manifest {}", manifest_path.display()))?;

    if manifest.build_id != hints.build_id {
        return Err(anyhow!(
            "build_id mismatch: manifest={} hints={}",
            manifest.build_id,
            hints.build_id
        ));
    }

    let mut chunks_updated = 0usize;
    let mut merge_suggestions = 0usize;
    for chunk in &mut manifest.chunks {
        let Some(hint) = hints.chunk_hints.get(&chunk.id) else {
            continue;
        };
        chunk.co_request_score = Some(hint.co_request_score);
        chunk.median_load_order = Some(hint.median_load_order);
        chunk.suggested_merge = hint.suggested_merge.clone();
        if hint.suggested_merge.is_some() {
            merge_suggestions += 1;
        }
        chunks_updated += 1;
    }

    // Write to a sibling temp file, then rename for atomicity.
    let dir = manifest_path
        .parent()
        .ok_or_else(|| anyhow!("manifest path has no parent: {}", manifest_path.display()))?;
    let file_name = manifest_path
        .file_name()
        .ok_or_else(|| anyhow!("manifest path has no file name"))?
        .to_string_lossy()
        .into_owned();

    let mut tmp = tempfile::Builder::new()
        .prefix(&format!(".{file_name}."))
        .suffix(".tmp")
        .tempfile_in(dir)
        .context("create manifest temp file")?;
    let json = serde_json::to_vec_pretty(&manifest).context("serialize updated manifest")?;
    tmp.write_all(&json).context("write manifest temp body")?;
    tmp.flush().context("flush manifest temp")?;
    tmp.as_file()
        .sync_all()
        .context("fsync manifest temp body")?;

    // `persist` consumes the NamedTempFile and renames over the destination.
    tmp.persist(manifest_path)
        .map_err(|e| anyhow!("persist manifest temp file: {e}"))?;

    Ok(UpdateStats {
        chunks_updated,
        merge_suggestions,
        manifest_build_id: manifest.build_id,
    })
}
```

```rust
    let store = PgoStore::open(db_path).context("open pgo db")?;
    let stats = ingest_log(&store, log_path).context("ingest telemetry log")?;
    println!(
        "ingested: lines={} new_sessions={} duplicates={} parse_errors={}",
        stats.lines_read,
        stats.sessions_inserted,
        stats.sessions_skipped_duplicate,
        stats.parse_errors,
    );
    Ok(())
}

/// `cloudpack pgo analyze [--db pgo.sqlite] [--manifest dist/manifest.json]`
pub fn cmd_analyze(db_path: &Path, manifest_path: &Path) -> Result<()> {
    let store = PgoStore::open(db_path).context("open pgo db")?;
    let bytes = std::fs::read(manifest_path)
        .with_context(|| format!("read manifest {}", manifest_path.display()))?;
    let manifest: ChunkManifest = serde_json::from_slice(&bytes).context("parse manifest")?;

    let hints = compute_hints(&store, &manifest, &C3Config::default())?;
    let total = hints.chunk_hints.len();
    let merges: usize = hints
        .chunk_hints
        .values()
        .filter(|h| h.suggested_merge.is_some())
        .count();
    println!(
        "analyze: build_id={} chunks={} suggested_merges={}",
        hints.build_id, total, merges
    );
    // Print per-chunk lines in deterministic order.
    let mut ids: Vec<&String> = hints.chunk_hints.keys().collect();
    ids.sort();
    for id in ids {
        let h = &hints.chunk_hints[id];
        println!(
            "  {id}: co_request_score={:.4} median_load_order={:.2} merge={}",
            h.co_request_score,
            h.median_load_order,
            h.suggested_merge.as_deref().unwrap_or("-"),
        );
    }
    Ok(())
}

/// `cloudpack pgo apply [--db pgo.sqlite] [--manifest dist/manifest.json]`
pub fn cmd_apply(db_path: &Path, manifest_path: &Path) -> Result<()> {
    let store = PgoStore::open(db_path).context("open pgo db")?;
    let bytes = std::fs::read(manifest_path)
        .with_context(|| format!("read manifest {}", manifest_path.display()))?;
    let manifest: ChunkManifest = serde_json::from_slice(&bytes).context("parse manifest")?;

    let hints = compute_hints(&store, &manifest, &C3Config::default())?;
    let stats = apply_hints(manifest_path, &hints)?;
    println!(
        "apply: build_id={} chunks_updated={} merge_suggestions={}",
        stats.manifest_build_id, stats.chunks_updated, stats.merge_suggestions,
    );
    Ok(())
}

/// `cloudpack pgo status [--db pgo.sqlite]`
pub fn cmd_status(db_path: &Path) -> Result<()> {
    let store = PgoStore::open(db_path).context("open pgo db")?;
    let sessions = store.session_count()?;
    let chunks = store.all_chunk_ids()?;
    let cfg = C3Config::default();
    let ready = sessions >= cfg.min_sessions;
    println!(
        "status: sessions={} unique_chunks={} ready_for_clustering={} (min_sessions={})",
        sessions,
        chunks.len(),
        ready,
        cfg.min_sessions,
    );
    Ok(())
}
```
