# Wundler Plan 4 — Adaptive Bundle Service (ABS)

**Status:** Ready for execution
**Date:** 2026-05-13
**Predecessors:** Plan 1 (Summarizer), Plan 2 (Graph Analyzer), Plan 3 (Pipeline / Level 0)
**Successor:** Plan 5 (PGO Store + chunk reorganization)

---

## Mission

Stand up the Adaptive Bundle Service: a small, fast HTTP server that takes a client's list of cached chunk hashes and returns the minimum set of CDN URLs it needs to render a given entry point. The ABS **never serves code** — the CDN does that. The ABS serves *manifests*.

The companion piece is a TypeScript service worker that talks to the ABS, caches the responses, falls back to a static manifest on the CDN when the ABS is unreachable, and emits telemetry the PGO Store will later consume.

This plan delivers Level 1 of the three-level deployment model from the design spec.

## Operating Invariants

1. **Code path is CDN-only.** ABS responses contain URLs and metadata. They never contain JavaScript source. A compromised ABS can redirect clients between *existing immutable* chunks; it cannot inject code.
2. **Static fallback is never optional.** Every ABS deployment publishes a static `manifest.json` to the CDN. If the ABS times out (default 100 ms), the service worker falls back to it. Level 0 keeps working when Level 1 is down.
3. **Manifests are signed at build time.** The pipeline (Plan 3) signs the `ChunkManifest` with an ed25519 key. The ABS verifies on load. The service worker can verify a manifest hash against an expected signature.
4. **Telemetry is append-only and write-cheap.** JSONL files, buffered writes, mutex-protected. The PGO Store (Plan 5) tails them. The ABS never reads them back.
5. **Build-id mismatch is the safety hatch.** When the client's known `build_id` doesn't match the ABS's current build, the ABS returns the entry's full chunk set, ignoring the client's cache claims. This is how we recover correctness during a deploy.

```rust
//! Wire types for the ABS HTTP protocol and telemetry log.

use serde::{Deserialize, Serialize};
use wundler_core::ContentHash;

/// Request body for POST /manifest.
///
/// The client tells the ABS what entry it's loading, which chunks
/// it already has cached, and (optionally) the build id it believes
/// it's coherent with.
#[derive(Debug, Clone, Deserialize, Serialize, PartialEq, Eq)]
pub struct ManifestRequest {
    /// Entry point key (must match an `entry_chunks` key in the manifest).
    pub entry_point: String,

    /// Content hashes of modules the client already has cached.
    /// A chunk is considered "already had" only if EVERY module in
    /// the chunk appears in this list.
    pub cached_hashes: Vec<ContentHash>,

    /// Optional: build id the client believes its cached chunks match.
    /// If absent or different from the ABS's current build, the ABS
    /// returns the entry's full chunk set.
    #[serde(default)]
    pub build_id: Option<String>,
}

/// Response body for POST /manifest.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct ManifestResponse {
    /// Build id the response is coherent with. If this changed since
    /// the client's last call, the client should plan a refresh.
    pub build_id: String,

    /// URLs the client MUST fetch before rendering.
    pub fetch_urls: Vec<String>,

    /// URLs the client SHOULD prefetch in idle time. Driven by
    /// `co_request_score` from the ChunkManifest.
    pub prefetch_urls: Vec<String>,

    /// Cache lifetime for this response, in seconds.
    pub ttl: u64,
}

/// One row appended to the JSONL telemetry log per /manifest call.
///
/// The PGO Store (Plan 5) ingests these to compute co-request scores
/// and suggested chunk merges.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct TelemetryEvent {
    /// Opaque session identifier from the client (does NOT identify
    /// the user; the SW generates a random per-session UUID).
    pub session_id: String,

    /// The entry point the client requested.
    pub entry_point: String,

    /// Chunk ids the ABS told the client to fetch.
    pub chunks_served: Vec<String>,

    /// Module hashes the client claimed to already have.
    pub client_had: Vec<ContentHash>,

    /// Server-side timestamp (ms since Unix epoch).
    pub timestamp_ms: u64,
}
```

```rust
//! Shared application state for the ABS server.

use anyhow::{Context, Result};
use std::path::Path;
use std::sync::Arc;
use tokio::sync::RwLock;
use wundler_graph::ChunkManifest;

/// Application state shared across all Axum handlers.
///
/// The `ChunkManifest` is wrapped in `Arc<RwLock<_>>` so that future
/// hot-reload support can swap it atomically without restarting the
/// server.
#[derive(Clone)]
pub struct AppState {
    pub manifest: Arc<RwLock<ChunkManifest>>,
    pub cdn_base_url: Arc<String>,
    pub ttl_seconds: u64,
}

impl AppState {
    /// Load a `ChunkManifest` from a JSON file on disk.
    pub async fn load_from_disk(
        manifest_path: &Path,
        cdn_base_url: String,
        ttl_seconds: u64,
    ) -> Result<Self> {
        let bytes = tokio::fs::read(manifest_path)
            .await
            .with_context(|| format!("read manifest at {}", manifest_path.display()))?;

        let manifest: ChunkManifest = serde_json::from_slice(&bytes)
            .with_context(|| format!("parse manifest at {}", manifest_path.display()))?;

        Ok(Self {
            manifest: Arc::new(RwLock::new(manifest)),
            cdn_base_url: Arc::new(cdn_base_url),
            ttl_seconds,
        })
    }
}
```

```rust
//! Delta manifest computation.
//!
//! Given a `ChunkManifest`, a client's request, and the CDN base URL,
//! returns the minimum set of fetch + prefetch URLs the client needs.

use crate::types::{ManifestRequest, ManifestResponse};
use std::collections::HashSet;
use wundler_core::ContentHash;
use wundler_graph::{Chunk, ChunkManifest};

/// Compute the delta manifest for a single /manifest request.
///
/// Logic:
/// 1. Resolve the entry's chunk list. Unknown entry → empty response.
/// 2. If `build_id` is absent or doesn't match the manifest's, treat
///    the client as having nothing cached (handled in Task 4).
/// 3. For each chunk in the entry list: if EVERY module in the chunk
///    is in `cached_hashes`, drop it; otherwise emit its CDN URL.
/// 4. Prefetch hints (Task 5) are added on top.
pub fn compute_delta(
    manifest: &ChunkManifest,
    request: &ManifestRequest,
    cdn_base_url: &str,
) -> ManifestResponse {
    let cached: HashSet<&ContentHash> = request.cached_hashes.iter().collect();

    let chunk_ids = match manifest.entry_chunks.get(&request.entry_point) {
        Some(ids) => ids.clone(),
        None => {
            return ManifestResponse {
                build_id: manifest.build_id.clone(),
                fetch_urls: vec![],
                prefetch_urls: vec![],
                ttl: 0,
            };
        }
    };

    let chunks_by_id: std::collections::HashMap<&str, &Chunk> = manifest
        .chunks
        .iter()
        .map(|c| (c.id.as_str(), c))
        .collect();

    let mut fetch_urls = Vec::new();
    for cid in &chunk_ids {
        let Some(chunk) = chunks_by_id.get(cid.as_str()) else {
            continue;
        };

        let client_has_all = !chunk.modules.is_empty()
            && chunk.modules.iter().all(|m| cached.contains(m));
        if client_has_all {
            continue;
        }
        fetch_urls.push(chunk_url(cdn_base_url, &chunk.hash));
    }

    ManifestResponse {
        build_id: manifest.build_id.clone(),
        fetch_urls,
        prefetch_urls: vec![],
        ttl: 0,
    }
}

fn chunk_url(base: &str, hash: &ContentHash) -> String {
    let trimmed = base.trim_end_matches('/');
    // ContentHash::to_hex returns the lowercase 64-char hex string.
    format!("{trimmed}/chunks/{}.js", &hash.to_hex()[..8])
}
```

```rust
/// Threshold above which a chunk's `co_request_score` qualifies it
/// for inclusion in `prefetch_urls`. Tuned by validation in Plan 5.
pub const PREFETCH_THRESHOLD: f64 = 0.7;

pub fn compute_delta(
    manifest: &ChunkManifest,
    request: &ManifestRequest,
    cdn_base_url: &str,
) -> ManifestResponse {
    let chunk_ids = match manifest.entry_chunks.get(&request.entry_point) {
        Some(ids) => ids.clone(),
        None => {
            return ManifestResponse {
                build_id: manifest.build_id.clone(),
                fetch_urls: vec![],
                prefetch_urls: vec![],
                ttl: 0,
            };
        }
    };

    let chunks_by_id: std::collections::HashMap<&str, &Chunk> = manifest
        .chunks
        .iter()
        .map(|c| (c.id.as_str(), c))
        .collect();

    let trust_cache = matches!(
        &request.build_id,
        Some(bid) if bid == &manifest.build_id
    );

    let cached: HashSet<&ContentHash> = if trust_cache {
        request.cached_hashes.iter().collect()
    } else {
        HashSet::new()
    };

    let mut fetch_urls = Vec::new();
    let mut fetched_ids: HashSet<&str> = HashSet::new();
    for cid in &chunk_ids {
        let Some(chunk) = chunks_by_id.get(cid.as_str()) else {
            continue;
        };

        let client_has_all = !chunk.modules.is_empty()
            && chunk.modules.iter().all(|m| cached.contains(m));
        if client_has_all {
            continue;
        }
        fetch_urls.push(chunk_url(cdn_base_url, &chunk.hash));
        fetched_ids.insert(chunk.id.as_str());
    }

    // Prefetch hints: any chunk in the manifest whose co_request_score
    // crosses the threshold, that the client doesn't already have
    // (when cache is trusted), and that isn't already in fetch_urls.
    let mut prefetch_urls = Vec::new();
    for chunk in &manifest.chunks {
        if fetched_ids.contains(chunk.id.as_str()) {
            continue;
        }
        let Some(score) = chunk.co_request_score else {
            continue;
        };
        if score < PREFETCH_THRESHOLD {
            continue;
        }
        let client_has_all = !chunk.modules.is_empty()
            && chunk.modules.iter().all(|m| cached.contains(m));
        if client_has_all {
            continue;
        }
        prefetch_urls.push(chunk_url(cdn_base_url, &chunk.hash));
    }

    ManifestResponse {
        build_id: manifest.build_id.clone(),
        fetch_urls,
        prefetch_urls,
        ttl: 0,
    }
}
```

```rust
//! Append-only JSONL telemetry log.
//!
//! Each /manifest call emits one `TelemetryEvent` record on its own line.
//! The PGO Store (Plan 5) tails this file to compute co-request scores.

use crate::types::TelemetryEvent;
use anyhow::{Context, Result};
use std::fs::{File, OpenOptions};
use std::io::{BufWriter, Write};
use std::path::Path;
use std::sync::{Arc, Mutex};

/// Buffered, mutex-protected JSONL writer.
///
/// Cloneable: clones share the same underlying writer + lock.
pub struct TelemetryLogger {
    writer: Arc<Mutex<BufWriter<File>>>,
}

impl TelemetryLogger {
    /// Open (create + append) a JSONL log file at `path`.
    /// Creates parent directories as needed.
    pub fn new(path: &Path) -> Result<Self> {
        if let Some(parent) = path.parent() {
            if !parent.as_os_str().is_empty() {
                std::fs::create_dir_all(parent)
                    .with_context(|| format!("create parent dir for {}", path.display()))?;
            }
        }
        let file = OpenOptions::new()
            .create(true)
            .append(true)
            .open(path)
            .with_context(|| format!("open telemetry log {}", path.display()))?;
        Ok(Self {
            writer: Arc::new(Mutex::new(BufWriter::new(file))),
        })
    }

    /// Serialize `event` and append it as one line to the log.
    /// Flushes after each write so the PGO Store can tail without lag.
    pub fn log(&self, event: &TelemetryEvent) -> Result<()> {
        let mut line = serde_json::to_vec(event).context("serialize TelemetryEvent")?;
        line.push(b'\n');

        let mut guard = self.writer.lock().expect("telemetry lock poisoned");
        guard.write_all(&line).context("write telemetry line")?;
        guard.flush().context("flush telemetry")?;
        Ok(())
    }
}

impl Clone for TelemetryLogger {
    fn clone(&self) -> Self {
        Self {
            writer: Arc::clone(&self.writer),
        }
    }
}

impl Drop for TelemetryLogger {
    fn drop(&mut self) {
        if let Ok(mut guard) = self.writer.lock() {
            let _ = guard.flush();
        }
    }
}
```

```rust
/// Build the Axum router. Exposed for tests so they can drive it
/// without binding a socket.
pub fn build_router(app: AppState, telemetry: TelemetryLogger) -> Router {

    Router::new()

        .route("/health", get(get_health))
        .route("/sw.js", get(get_service_worker))
        .with_state(state)

/// Run the ABS to completion. Returns when the server shuts down.
pub async fn run(config: AbsConfig) -> anyhow::Result<()> {
    let app = AppState::load_from_disk(
        &config.manifest_path,
        config.cdn_base_url.clone(),
        config.ttl_seconds,
    )
    .await?;
    let telemetry = TelemetryLogger::new(&config.telemetry_log)?;
    let router = build_router(app, telemetry);

    let addr: std::net::SocketAddr = format!("0.0.0.0:{}", config.port).parse()?;
    let listener = tokio::net::TcpListener::bind(addr).await?;
    tracing::info!("wundler-abs listening on {addr}");
    axum::serve(listener, router).await?;
    Ok(())
}

async fn post_manifest(
    State(state): State<RouterState>,
    Json(req): Json<ManifestRequest>,
) -> Result<Json<ManifestResponse>, ManifestError> {
    let manifest = state.app.manifest.read().await;
    let mut resp = compute_delta(&manifest, &req, &state.app.cdn_base_url);
    resp.ttl = state.app.ttl_seconds;

    // Extract chunk ids from fetch_urls for telemetry.
    let chunks_served: Vec<String> = manifest
        .entry_chunks
        .get(&req.entry_point)
        .cloned()
        .unwrap_or_default();

    let ev = TelemetryEvent {
        session_id: req
            .build_id
            .clone()
            .unwrap_or_else(|| "anonymous".to_string()),
        entry_point: req.entry_point.clone(),
        chunks_served,
        client_had: req.cached_hashes.clone(),
        timestamp_ms: now_ms(),
    };
    if let Err(e) = state.telemetry.log(&ev) {
        tracing::warn!("telemetry log failed: {e:#}");
    }

    Ok(Json(resp))
}
```

```rust
//! ed25519 signing & verification of ChunkManifests.
//!
//! The build pipeline (Plan 3) signs the manifest with the private
//! key. The ABS verifies the signature on load using the public key.
//! Service workers can also verify by hashing the canonical manifest
//! bytes and comparing against an expected signature.

use anyhow::{anyhow, Context, Result};
use ed25519_dalek::pkcs8::{DecodePrivateKey, DecodePublicKey, EncodePrivateKey, EncodePublicKey};
use ed25519_dalek::{Signature, Signer, SigningKey, Verifier, VerifyingKey};
use rand::rngs::OsRng;
use wundler_graph::ChunkManifest;

/// A freshly generated ed25519 key pair in PEM form.
pub struct KeyPairPem {
    pub signing_key_pem: String,
    pub verifying_key_pem: String,
}

/// Generate a new ed25519 keypair.
pub fn generate_keypair() -> KeyPairPem {
    let signing = SigningKey::generate(&mut OsRng);
    let verifying: VerifyingKey = signing.verifying_key();

    let signing_pem = signing
        .to_pkcs8_pem(ed25519_dalek::pkcs8::spki::der::pem::LineEnding::LF)
        .expect("encode signing key");
    let verifying_pem = verifying
        .to_public_key_pem(ed25519_dalek::pkcs8::spki::der::pem::LineEnding::LF)
        .expect("encode verifying key");

    KeyPairPem {
        signing_key_pem: signing_pem.to_string(),
        verifying_key_pem: verifying_pem,
    }
}

/// Build-time signer.
pub struct ManifestSigner {
    signing_key: SigningKey,
}

impl ManifestSigner {
    pub fn from_pem(pem: &str) -> Result<Self> {
        let key = SigningKey::from_pkcs8_pem(pem).context("parse signing key PEM")?;
        Ok(Self { signing_key: key })
    }

    pub fn sign_manifest(&self, manifest: &ChunkManifest) -> Signature {
        let bytes = manifest_signature_bytes(manifest);
        self.signing_key.sign(&bytes)
    }
}

/// Runtime verifier (used by ABS on load).
pub struct ManifestVerifier {
    verifying_key: VerifyingKey,
}

impl ManifestVerifier {
    pub fn from_pem(pem: &str) -> Result<Self> {
        let key = VerifyingKey::from_public_key_pem(pem).context("parse verifying key PEM")?;
        Ok(Self { verifying_key: key })
    }

    pub fn verify(&self, manifest: &ChunkManifest, sig: &Signature) -> Result<()> {
        let bytes = manifest_signature_bytes(manifest);
        self.verifying_key
            .verify(&bytes, sig)
            .map_err(|e| anyhow!("manifest signature verification failed: {e}"))
    }
}

/// Canonical byte representation of a `ChunkManifest` for signing.
///
/// Deterministic: build_id, then sorted chunk ids paired with their
/// content hashes. We deliberately do NOT include co-request scores
/// or other PGO fields — those are advisory and may change between
/// builds without invalidating the integrity of the chunks themselves.
pub fn manifest_signature_bytes(manifest: &ChunkManifest) -> Vec<u8> {
    let mut chunks: Vec<(&str, &str)> = manifest
        .chunks
        .iter()
        .map(|c| (c.id.as_str(), c.hash.to_hex_str()))
        .collect();
    chunks.sort_by(|a, b| a.0.cmp(b.0));

    let mut out = Vec::with_capacity(64 + chunks.len() * 80);
    out.extend_from_slice(manifest.build_id.as_bytes());
    out.push(b'\n');
    for (id, h) in chunks {
        out.extend_from_slice(id.as_bytes());
        out.push(b' ');
        out.extend_from_slice(h.as_bytes());
        out.push(b'\n');
    }
    out
}
```

> **Implementation note:** `ContentHash::to_hex_str` is assumed to return `&str` (a borrowed view into the hash). If only `to_hex() -> String` is available from Plan 1, change the call to `c.hash.to_hex()` and clone. The exact API is finalized in Plan 1 Task 2.

```rust
use crate::signing::ManifestVerifier;
use anyhow::{Context, Result};
use ed25519_dalek::Signature;
use std::path::Path;
use std::sync::Arc;
use tokio::sync::RwLock;
use wundler_graph::ChunkManifest;

#[derive(Clone)]
pub struct AppState {
    pub manifest: Arc<RwLock<ChunkManifest>>,
    pub cdn_base_url: Arc<String>,
    pub ttl_seconds: u64,
}

impl AppState {
    pub async fn load_from_disk(
        manifest_path: &Path,
        cdn_base_url: String,
        ttl_seconds: u64,
    ) -> Result<Self> {
        Self::load_signed_from_disk(manifest_path, cdn_base_url, ttl_seconds, None).await
    }

    /// Load + optionally verify a signed `ChunkManifest`.
    pub async fn load_signed_from_disk(
        manifest_path: &Path,
        cdn_base_url: String,
        ttl_seconds: u64,
        verify: Option<(&ManifestVerifier, &Signature)>,
    ) -> Result<Self> {
        let bytes = tokio::fs::read(manifest_path)
            .await
            .with_context(|| format!("read manifest at {}", manifest_path.display()))?;
        let manifest: ChunkManifest = serde_json::from_slice(&bytes)
            .with_context(|| format!("parse manifest at {}", manifest_path.display()))?;

        if let Some((verifier, sig)) = verify {
            verifier
                .verify(&manifest, sig)
                .context("manifest signature verification failed")?;
        }

        Ok(Self {
            manifest: Arc::new(RwLock::new(manifest)),
            cdn_base_url: Arc::new(cdn_base_url),
            ttl_seconds,
        })
    }
}
```

```typescript
 * Responsibilities:
 *   - On install: warm the static fallback manifest from CDN.
 *   - On activate: claim all clients so updates take effect immediately.
 *   - On fetch (Task 13): intercept navigation, talk to ABS, fill cache.
 *   - On build-id rotation (Task 14): postMessage to clients.

import type { SwConfig } from "./types";

/** Installation: fetch + cache the static fallback manifest. */
export async function installHandler(config: SwConfig): Promise<void> {
  const cache = await getCache(config.cache);
  try {
    const resp = await fetch(`${config.cdnBaseUrl}/manifest.json`, {
      cache: "no-cache",

    console.warn("[wundler-sw] install: manifest prefetch failed", err);

  // eslint-disable-next-line @typescript-eslint/no-explicit-any
  const c = (globalThis as any).clients as { claim: () => Promise<void> } | undefined;
  if (c) {
    await c.claim();
  }
}
```

```typescript
import type {
  CacheLike,
  ManifestRequest,
  ManifestResponse,
  StaticManifest,
  SwConfig,
} from "./types";
import { STATIC_MANIFEST_KEY } from "./cache";

/** Default ABS timeout — the static fallback kicks in past this. */
export const DEFAULT_ABS_TIMEOUT_MS = 100;

export interface NavigationOptions {
  /** Override the ABS request timeout. */
  absTimeoutMs?: number;
}

/**
 * Collect every chunk hash currently stored in cache (by URL convention:
 * `${cdnBase}/chunks/{firstHexBytes}.js`). Used as the `cached_hashes`
 * payload to the ABS. We send the FULL content hash of each module,
 * which the ABS knows from `module_index`.
 *
 * Strategy: read the static manifest from cache, walk its chunks,
 * keep only those whose hash file exists in cache, then emit the
 * module hashes of those chunks.
 */
export async function collectCachedModuleHashes(
  cache: CacheLike,
  cdnBaseUrl: string,
): Promise<{ static_: StaticManifest | null; hashes: string[] }> {
  const staticResp = await cache.match(STATIC_MANIFEST_KEY);
  if (!staticResp) return { static_: null, hashes: [] };
  const static_: StaticManifest = await staticResp.json();
  const hashes: string[] = [];
  for (const chunk of static_.chunks) {
    const url = `${cdnBaseUrl}/chunks/${chunk.hash.slice(0, 8)}.js`;
    const cached = await cache.match(url);
    if (cached) {
      for (const m of chunk.modules) hashes.push(m);
    }
  }
  return { static_, hashes };
}

/**
 * POST to the ABS with a timeout. Resolves to `null` on timeout or
 * any non-2xx response — callers must handle the fallback.
 */
export async function fetchDelta(
  config: SwConfig,
  request: ManifestRequest,
  timeoutMs: number,
): Promise<ManifestResponse | null> {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), timeoutMs);
  try {
    const resp = await fetch(`${config.absBaseUrl}/manifest`, {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify(request),
      signal: controller.signal,
    });
    if (!resp.ok) return null;
    return (await resp.json()) as ManifestResponse;
  } catch {
    return null;
  } finally {
    clearTimeout(timer);
  }
}

/**
 * Resolve the URLs needed for an entry point from the static manifest.
 * Used as the fallback path when ABS is unreachable.
 */
export function staticFallbackUrls(
  static_: StaticManifest,
  entryPoint: string,
  cdnBaseUrl: string,
): string[] {
  const ids = static_.entry_chunks[entryPoint] ?? [];
  const byId = new Map(static_.chunks.map((c) => [c.id, c]));
  const out: string[] = [];
  for (const id of ids) {
    const c = byId.get(id);
    if (!c) continue;
    out.push(`${cdnBaseUrl}/chunks/${c.hash.slice(0, 8)}.js`);
  }
  return out;
}
```

```typescript
/**
 * Drive a single navigation request. Called from the `fetch` event
 * handler in production, exported for direct testing.
 *
 * Returns the list of chunk URLs the page needs (the caller writes
 * the response). Cache is updated as a side effect.
 */
export async function handleNavigation(
  config: SwConfig,
  entryPoint: string,
  opts: NavigationOptions = {},
): Promise<string[]> {
  const cache = await getCache(config.cache);
  const { static_, hashes } = await collectCachedModuleHashes(cache, config.cdnBaseUrl);

  const buildId = static_?.build_id;
  const request = { entry_point: entryPoint, cached_hashes: hashes, build_id: buildId };
  const timeoutMs = opts.absTimeoutMs ?? DEFAULT_ABS_TIMEOUT_MS;
  const delta = await fetchDelta(config, request, timeoutMs);

  let urlsToFetch: string[];
  let urlsToPrefetch: string[] = [];
  if (delta) {
    urlsToFetch = delta.fetch_urls;
    urlsToPrefetch = delta.prefetch_urls;
  } else if (static_) {
    urlsToFetch = staticFallbackUrls(static_, entryPoint, config.cdnBaseUrl);
  } else {
    urlsToFetch = [];
  }

  // Fetch all required chunks into cache (in parallel).
  await Promise.all(
    urlsToFetch.map(async (url) => {
      const existing = await cache.match(url);
      if (existing) return;
      const resp = await fetch(url);
      if (resp.ok) await cache.put(url, resp.clone());
    }),
  );

  // Fire-and-forget the prefetch list.
  for (const url of urlsToPrefetch) {
    void (async () => {
      try {
        const existing = await cache.match(url);
        if (existing) return;
        const resp = await fetch(url);
        if (resp.ok) await cache.put(url, resp.clone());
      } catch {
        /* ignore */
      }
    })();
  }

  return urlsToFetch;
}
```

```typescript
export async function notifyBuildIdChanged(newBuildId: string): Promise<void> {
  // eslint-disable-next-line @typescript-eslint/no-explicit-any
```

```typescript
import { notifyBuildIdChanged } from "./buildid";

export async function handleNavigation(
  config: SwConfig,
  entryPoint: string,
  opts: NavigationOptions = {},
): Promise<string[]> {
  const cache = await getCache(config.cache);
  const { static_, hashes } = await collectCachedModuleHashes(cache, config.cdnBaseUrl);

  const buildId = static_?.build_id;
  const request = { entry_point: entryPoint, cached_hashes: hashes, build_id: buildId };
  const timeoutMs = opts.absTimeoutMs ?? DEFAULT_ABS_TIMEOUT_MS;
  const delta = await fetchDelta(config, request, timeoutMs);

  if (delta && buildId && delta.build_id !== buildId) {
    await notifyBuildIdChanged(delta.build_id);
    // Best-effort: refresh the cached static manifest in the background.
    void (async () => {
      try {
        const resp = await fetch(`${config.cdnBaseUrl}/manifest.json`, { cache: "no-cache" });
        if (resp.ok) await cache.put(STATIC_MANIFEST_KEY, resp.clone());
      } catch {
        /* ignore */
      }
    })();
  }

  let urlsToFetch: string[];
  let urlsToPrefetch: string[] = [];
  if (delta) {
    urlsToFetch = delta.fetch_urls;
    urlsToPrefetch = delta.prefetch_urls;
  } else if (static_) {
    urlsToFetch = staticFallbackUrls(static_, entryPoint, config.cdnBaseUrl);
  } else {
    urlsToFetch = [];
  }

  await Promise.all(
    urlsToFetch.map(async (url) => {
      const existing = await cache.match(url);
      if (existing) return;
      const resp = await fetch(url);
      if (resp.ok) await cache.put(url, resp.clone());
    }),
  );

  for (const url of urlsToPrefetch) {
    void (async () => {
      try {
        const existing = await cache.match(url);
        if (existing) return;
        const resp = await fetch(url);
        if (resp.ok) await cache.put(url, resp.clone());
      } catch {
        /* ignore */
      }
    })();
  }

  return urlsToFetch;
}
```

```rust
use anyhow::{Context, Result};

    #[command(subcommand)]

    /// Build a ChunkManifest + chunk files (Plan 3).

    // ... other Plan 1/2 subcommands remain in their existing form.

    #[arg(long, default_value = "signing.pem")]

    #[arg(long, default_value = "verifying.pem")]

#[derive(Deserialize)]
struct AbsTomlConfig {
    manifest_path: PathBuf,
    cdn_base_url: String,
    telemetry_log: PathBuf,
    signing_key_pem: Option<PathBuf>,
    #[serde(default = "default_port")]

fn default_port() -> u16 { 8080 }
fn default_ttl() -> u64 { 300 }

async fn main() -> Result<()> {
    tracing_subscriber::fmt::try_init().ok();
    let cli = Cli::parse();
    match cli.command {
        Cmd::Abs(args) => match args.cmd {
            AbsCmd::Serve(s) => run_abs_serve(s).await,
            AbsCmd::Keygen(k) => run_abs_keygen(k),
        },
        Cmd::Build(b) => run_build(b).await,
    }
}

async fn run_abs_serve(args: AbsServeArgs) -> Result<()> {
    let bytes = std::fs::read(&args.config)
        .with_context(|| format!("read abs config at {}", args.config.display()))?;
    let toml_cfg: AbsTomlConfig = toml::from_slice(&bytes).context("parse abs config TOML")?;
    let cfg = AbsConfig {
        manifest_path: toml_cfg.manifest_path,
        cdn_base_url: toml_cfg.cdn_base_url,
        telemetry_log: toml_cfg.telemetry_log,
        signing_key_pem: toml_cfg.signing_key_pem,
        port: toml_cfg.port,
        ttl_seconds: toml_cfg.ttl_seconds,
    };
    abs_run(cfg).await
}

fn run_abs_keygen(args: AbsKeygenArgs) -> Result<()> {
    let kp = generate_keypair();
    if let Some(parent) = args.signing_out.parent() {
        if !parent.as_os_str().is_empty() {
            std::fs::create_dir_all(parent).ok();
        }
    }
    if let Some(parent) = args.verifying_out.parent() {
        if !parent.as_os_str().is_empty() {
            std::fs::create_dir_all(parent).ok();
        }
    }
    std::fs::write(&args.signing_out, &kp.signing_key_pem)
        .with_context(|| format!("write signing key to {}", args.signing_out.display()))?;
    std::fs::write(&args.verifying_out, &kp.verifying_key_pem)
        .with_context(|| format!("write verifying key to {}", args.verifying_out.display()))?;
    eprintln!(
        "wrote signing key → {}\nwrote verifying key → {}",
        args.signing_out.display(),
        args.verifying_out.display(),
    );
    Ok(())
}

async fn run_build(args: BuildArgs) -> Result<()> {
    // Delegate the heavy lifting to the pipeline (Plan 3).
    let manifest = wundler_pipeline::build(&args.root, &args.out).await?;

    if args.sign {
        let key_path = args
            .key
            .as_ref()
            .ok_or_else(|| anyhow::anyhow!("--sign requires --key <PEM_PATH>"))?;
        let pem = std::fs::read_to_string(key_path)
            .with_context(|| format!("read signing key {}", key_path.display()))?;
        let signer = ManifestSigner::from_pem(&pem)?;
        let sig = signer.sign_manifest(&manifest);
        let sig_path = args.out.join("manifest.sig");
        std::fs::write(&sig_path, sig.to_bytes()).context("write manifest signature")?;
        eprintln!("signed manifest → {}", sig_path.display());
    }

    Ok(())
}
```

## Out of Scope for Plan 4

- PGO ingestion: parsing `telemetry.jsonl` and updating `co_request_score` values. That lives in Plan 5.
- ABS hot reload of the manifest. The `Arc<RwLock<_>>` is the seam; Plan 5 (or a small follow-up) wires file-watch + atomic swap.
- Geo-distributed ABS deployment, rate limiting, TLS termination. These are deployment concerns outside the code path.
- Service-worker integrity verification of chunk hashes against the signed manifest. The plumbing (`manifest.sig` next to `manifest.json`) is in place; the SW-side verification lands in Plan 5 along with the PGO loop because both need ed25519 verification in the worker.

## Risks and Mitigations

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| `axum-test` API drift between minor versions | medium | low | Pin to `0.15.x`; the integration test surface is small enough to port if needed. |
| `ed25519-dalek` PEM helpers change between releases | low | medium | Wrap PEM I/O in our `signing.rs` so a future migration touches one file. |
| Service Worker test harness diverges from real browsers | medium | medium | Tests exercise pure functions (`installHandler`, `handleNavigation`); browser-shaped integration is validated by manual smoke in Plan 5. |
| TOML config drift between this plan and Plan 3 | low | low | The `AbsTomlConfig` struct is fully isolated to the CLI; renames are a 1-file change. |
| Manifest signature scheme excludes a field that later proves important | low | high | `manifest_signature_bytes` is the single source of truth; bumping a `signature_version` byte at the front of the payload buys forward compatibility without breaking old verifiers. |
